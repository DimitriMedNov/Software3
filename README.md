# Ingeniería de Software III — demo con Spring

Demo de Spring Boot de la materia de ingeniería de software III, en la Universidad Anáhuac Mayab.

## Qué contiene

En `demoSpring/`, un CRUD parcial de productos: la entidad `Product`, su repositorio, su servicio con implementación, los controladores y vistas en Thymeleaf con Bootstrap.

## Stack

Java · Spring Boot · Thymeleaf · Maven

> Es una versión recortada del mismo ejercicio. El completo, con capa REST incluida, está en `DEMOSPMEDINANOVELO`.
